# 🌸 GARDEN OF US — Asset Prompt Library
### Pixel-Art Kawaii Arcade Edition

This is your complete prompt sheet for every image asset in the romantic garden web app. Every prompt locks into the same retro pixel-art / kawaii vaporwave / 16-bit arcade visual DNA so the app feels cohesive on Reels and TikTok.

> **Tools that work best:** Midjourney v6 (`--style raw --v 6 --ar X:Y`), FLUX 1.1 Pro, DALL-E 3, Leonardo Pixel-Art model, Recraft pixel-art style.

## 🎨 MASTER STYLE TOKEN
**Append this to every prompt for cohesion. Copy once, reuse always.**

```
16-bit pixel art, retro arcade aesthetic, kawaii vaporwave color palette 
(soft teal sky #9EE5E5, hot pink #FF6BB5, peach cream #FFD4B8, mint green 
#B8F4D4, lavender #C8B6FF, cream yellow #FFF4B8, dusty rose #FFA5C0), 
crisp 2px black pixel outlines, chunky low-resolution sprites, flat 
arcade-era shading with dithered highlights, kawaii face details with 
blush dots and round eyes, playful neon pastel tones, hard pixel edges, 
no anti-aliasing, Nintendo-style platformer meets modern kawaii cyberpop 
branding, optimized for TikTok/Reels motion graphics
```

**Universal negative prompt:**
```
3D render, photorealistic, blurry, smooth shading, gradient mesh, 
realistic skin, watercolor, oil painting, sketch, low quality, 
distorted, anti-aliased, soft edges
```

## 🎯 10. PROMPT POWER-UPS

**For sharper pixel-art results, add these:**
- `pixel-perfect, no smoothing, hard edges`
- `--stylize 100 --style raw` (Midjourney)
- `clean pixel art, 16-bit Super Nintendo aesthetic`
- `consistent palette of 12 colors maximum`
- `viewed from front, isometric, or 3/4 angle`

**For transparent backgrounds:**
- Add: `transparent background, isolated subject, no scenery`
- Midjourney: doesn't natively support transparent — generate on solid color and remove BG in Photoshop/Photopea, OR use **Recraft** which exports PNG with alpha.

**For matching characters across generations (consistency):**
- Lock character description as a saved "character sheet" prompt
- Use Midjourney `--cref [URL]` with first good result
- Use FLUX with the same seed across generations

## 🚀 SUGGESTED WORKFLOW

1. **Generate the master couple character first.** Get one perfect chibi couple sprite. Save the seed/cref.
2. **Generate all 8 flower sprites** using consistent prompts. These are your inventory.
3. **Build parallax background layers** separately (sky / mid / foreground).
4. **Generate hero scene composition** for the form page.
5. **Generate the 9 bouquet variations** as premium content.
6. **UI elements last** — these are easiest and most flexible.
7. **Particles & effects** for the final polish layer.

> **Pro tip:** Run all flower sprites in the same Midjourney session with the same `--seed` to maintain color consistency across the whole flower roster.
