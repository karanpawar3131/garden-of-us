# 🌸 Garden of Us — Essential Asset Prompts
### True 2D Pixel Art Edition (no 3D drift)

---

## ⚠️ Why your last batch came out 3D

Image gen tools default to rendered-looking output unless you anchor them hard to 2D. The fix:
- ❌ Avoid: "chunky", "isometric", "3D model", "voxel", "Minecraft", "Roblox"
- ✅ Use: "flat 2D", "side view", "front-facing", "no depth", "Stardew Valley", "GBA sprite"
- ✅ Reference real 2D games: **Stardew Valley, Celeste, Owlboy, Eastward, Undertale**

---

## 🛠️ Best Tools for Actual 2D Pixel Art

| Tool | Why |
|------|-----|
| **Recraft** | Dedicated pixel-art style + transparent PNG export |
| **Leonardo (Pixel Art model)** | Trained on real 2D sprites, less 3D drift |
| **PixelLab.ai** | Built specifically for game sprites |
| **Midjourney v6** | Works if you anchor hard with `--style raw` |
| **Scenario.gg** | Pixel art LoRAs, sprite sheet generation |

> **Strong recommendation:** Run these prompts through **Recraft** or **Leonardo Pixel Art model**, not Midjourney. You'll save hours.

# 🎯 Workflow

1. **Start with Asset 1 (the couple).** Generate it first. Once you have a version you love, save the image URL — you'll use `--cref` (Midjourney) or seed lock (FLUX/Leonardo) to keep characters consistent.
2. **Generate 5 flowers in one session** with the same seed for color consistency.
3. **Generate 3 backgrounds (2, 3, 6)** with the same seed.
4. **UI elements (7, 8, 9, 10)** can be generated last in any order.
5. **Bouquet (4) + Envelope (5)** are your "money shot" assets for the reveal — spend the most prompt iterations on these.

## Two final tips

**For transparent backgrounds:** Midjourney can't do it natively. Use **Recraft** (built-in PNG alpha) or generate on a flat magenta `#FF00FF` background and remove in Photopea (free, browser-based) using Magic Wand.

**For character consistency:** Generate the couple ONCE, perfectly. Then for every other scene needing them, use Midjourney `--cref [image_url]` or paste the image as a reference in Leonardo. Otherwise their faces will subtly drift across the app and the brand will feel off.
